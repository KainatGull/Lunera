# LUNÉRA React conversion

Converted from the supplied HTML/CSS/JS site into a React + Vite app.

## Run
```bash
npm install
npm run dev
```

Pages:
- `/` Home
- `/shop` Shop/filter/search
- `/product?id=aleo-tube` Product detail
- `/about` About
- `/cart` Cart
- `/checkout` Checkout
- `/admin` Admin dashboard

Cart, wishlist, orders and product edits use browser localStorage, matching the original site's client-side approach.
